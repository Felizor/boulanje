# ORJEUN Production

Site web pou ORJEUN Production - yon platfòm pou vann pwodui ak sèvis.

## Ki sa ki nan pwojè sa a?

Pwojè sa a se yon sit wèb senp pou montre ak vann pwodui. Li gen:
- Yon lis pwodui ak sèvis
- Sistèm rechèch
- Kategori pwodui
- Triye pa pri oswa alfabè
- Entegrasyon WhatsApp pou kòmand

## Kòman pou w itilize sit wèb la

1. Ouvri fichye `index.html` nan yon navigatè wèb (Chrome, Firefox, etc.)
2. Sit wèb la ap chaje ak tout pwodui yo
3. Kliyan yo ka:
   - Rechèche pwodui
   - Filtre pa kategori
   - Ajoute pwodui nan panye
   - Voye kòmand atravè WhatsApp

## Kòman pou w mete pwojè sa a sou GitHub

### 1. Kreye yon kont GitHub
- Ale sou [github.com](https://github.com)
- Klike sou "Sign up" pou kreye yon kont

### 2. Kreye yon nouvo repo
- Klike sou bouton "+" an wo adwat
- Chwazi "New repository"
- Bay yon non repo a (tankou "boulanje")
- Chwazi si repo a piblik oswa prive
- Klike "Create repository"

### 3. Pouse kòd ou sou GitHub
Si w gen Git enstale sou òdinatè w:

```bash
# Inisyalize Git nan dosye pwojè w la
git init

# Ajoute tout fichye yo
git add .

# Fè yon commit
git commit -m "Premye commit"

# Konekte ak repo GitHub ou
git remote add origin https://github.com/USERNAME/REPO-NAME.git

# Pouse kòd la
git push -u origin main
```

### 4. Mete sit wèb la sou entènèt ak GitHub Pages
- Ale nan repo GitHub ou
- Klike sou "Settings"
- Klike sou "Pages" nan menu agoch la
- Nan "Source", chwazi branch "main"
- Klike "Save"
- Sit wèb ou ap disponib nan: `https://USERNAME.github.io/REPO-NAME/`

# ORJEUN Production (English)

Website for ORJEUN Production - a platform for selling products and services.

## What's in this project?

This is a simple website to display and sell products. It includes:
- Product and service listings
- Search system
- Product categories
- Sort by price or alphabetically
- WhatsApp integration for orders

## How to use the website

1. Open the `index.html` file in a web browser (Chrome, Firefox, etc.)
2. The website will load with all products
3. Customers can:
   - Search for products
   - Filter by category
   - Add products to cart
   - Send orders via WhatsApp

## How to put this project on GitHub

### 1. Create a GitHub account
- Go to [github.com](https://github.com)
- Click "Sign up" to create an account

### 2. Create a new repository
- Click the "+" button at the top right
- Choose "New repository"
- Give the repository a name (like "boulanje")
- Choose if the repo is public or private
- Click "Create repository"

### 3. Push your code to GitHub
If you have Git installed on your computer:

```bash
# Initialize Git in your project folder
git init

# Add all files
git add .

# Make a commit
git commit -m "First commit"

# Connect to your GitHub repo
git remote add origin https://github.com/USERNAME/REPO-NAME.git

# Push the code
git push -u origin main
```

### 4. Deploy the website online with GitHub Pages
- Go to your GitHub repository
- Click on "Settings"
- Click on "Pages" in the left menu
- Under "Source", select the "main" branch
- Click "Save"
- Your website will be available at: `https://USERNAME.github.io/REPO-NAME/`
