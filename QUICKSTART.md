# Kòmansou Rapid / Quick Start

## Kòman pou w itilize sit wèb la / How to use the website

### An Kreyòl
1. Ouvri fichye `index.html` nan navigatè w (Chrome, Firefox, etc.)
2. Sit wèb la ap chaje otomatikman
3. Sa ou ka fè:
   - Rechèche pwodui
   - Chwazi kategori
   - Ajoute pwodui nan panye
   - Voye kòmand pa WhatsApp

### In English
1. Open the `index.html` file in your browser (Chrome, Firefox, etc.)
2. The website will load automatically
3. What you can do:
   - Search for products
   - Choose categories
   - Add products to cart
   - Send orders via WhatsApp

## Kòman pou w mete pwojè a sou GitHub / How to put the project on GitHub

### Etap Rapid / Quick Steps

#### 1. Kreye kont GitHub / Create GitHub account
👉 [GitHub.com/signup](https://github.com/signup)

#### 2. Kreye repo / Create repository
- Klike "+" → "New repository"
- Bay yon non / Give it a name
- Klike "Create repository"

#### 3. Pouse kòd la / Push the code
```bash
git init
git add .
git commit -m "First commit"
git remote add origin https://github.com/USERNAME/REPO-NAME.git
git push -u origin main
```

#### 4. Mete l sou entènèt / Deploy online
- Ale nan Settings → Pages
- Chwazi branch "main"
- Klike "Save"
- ✅ Sit ou disponib nan: `https://USERNAME.github.io/REPO-NAME/`
